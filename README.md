# Sewer-Code-Search

A search tool for exploring and navigating sewer/stormwater modeling source code, with a focus on SWMM5 and related hydraulic modeling engines.

## Overview

Sewer-Code-Search helps engineers and developers quickly locate functions, variables, subroutines, and code patterns across large hydraulic modeling codebases. It is designed to support reverse-engineering, code review, and onboarding workflows for stormwater infrastructure software.

## Features

- Fast keyword and symbol search across source files
- Filters by file type (e.g., `.c`, `.h`, `.f`, `.py`)
- Context-aware results showing surrounding code
- Designed for SWMM5 and ICM InfoWorks-related codebases
- Browser-based UI for easy access

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/SWMMEnablement/Sewer-Code-Search.git
   ```
2. Follow setup instructions (to be added) for indexing your target codebase.
3. Launch the search interface and start exploring.
